# Dariyapur Shiv Mandir Kanti

A modern, responsive, and SEO-optimized temple website built with React, TypeScript, Tailwind CSS, and Sanity CMS.
Designed to provide devotees and visitors with an engaging digital experience through dynamic content management, beautiful galleries, community updates, and essential temple information.

🌐Live Website: https://dariyapurshivmandirkantiorg.vercel.app

📂GitHub Repository: https://github.com/Adii-27/dariyapurshivmandirkanti


#Overview

Dariyapur Shiv Mandir Kanti is a modern web platform developed to strengthen the temple's digital presence and make information easily accessible to devotees worldwide.

The website allows visitors to explore the temple's history, browse photo galleries, read community announcements, locate the temple using Google Maps, and stay connected with upcoming activities.

Content is managed through **Sanity CMS**, enabling administrators to update information without modifying the source code. The application follows a mobile-first approach with a strong focus on performance, accessibility, and search engine optimization.

#Getting Started

1. Clone the Repository

```bash
git clone https://github.com/Adii-27/dariyapurshivmandirkanti.git
```

2. Navigate to the Project

```bash
cd dariyapurshivmandirkanti
```

3. Install Dependencies

```bash
npm install
```

4. Configure Environment Variables

Create a `.env` file in the project root and add your Sanity configuration.

```env
VITE_SANITY_PROJECT_ID=your_project_id
VITE_SANITY_DATASET=production
VITE_SANITY_API_VERSION=2025-01-01
```

5. Run the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
